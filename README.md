# WinScript Support

WinScript Support 是一个面向 IntelliJ 平台（IDEA Community Edition / 统一免费版 2025.3+）的插件，为 Windows 脚本提供开箱即用的基础支持：Batch（`.bat` / `.cmd`）与 PowerShell（`.ps1`）的语法高亮、脚本运行配置与空命令执行，不强制用户安装外部服务。

当前处于设计阶段，功能范围、技术架构、模块划分与里程碑见[插件规格设计文档.md](插件规格设计文档.md)。
